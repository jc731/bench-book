## Findings

### F1. "End Q4…" label cut off

- Screen: live game, bottom bar.
- Event: 43.
- Expected: a button that says plainly what it does at the end of regulation.
- Did: tapped the red "End Q4…" button.
- Happened: it worked (it asked "Start overtime" or "End game (no overtime)"), but at
  phone width the label is truncated, so the persona had to guess what it did.
- Severity: hesitated.
- Suggested direction: a shorter label that fits, or let that button take more width in
  Q4.
- Screenshot: v0.6.0/end-q4-label.png

### F2. Quarter check's foul list shows game totals under a per-quarter heading

- Screen: Check Qn (seen on Check Q4 from the Final screen).
- Event: 43 (applies to every check).
- Expected: the fouls listed under "Team fouls in Q4: 1" to be Q4's fouls (only #3).
- Did: compared the list with the book, as the heading "Fouls (compare with the book by
  eye)" asks.
- Happened: the list showed game totals (#3 1, #5 1, #7 2, …), so it read as wrong for Q4.
- Severity: hesitated.
- Suggested direction: either list this quarter's fouls, or label the list as game totals
  so it doesn't sit under the per-quarter count.
- Screenshot: v0.6.0/check-q4-fouls.png

### F3. Ending Q1 to Q3 has no confirmation

- Screen: live game, end-of-quarter button.
- Event: 12 (also 27, 36).
- Expected: a confirmation, since a stray thumb tap would end the quarter.
- Did: tapped End Q1.
- Happened: it went straight to Q2 and offered "Check Q1". Q4 does ask (overtime or end
  game).
- Severity: hesitated. Theoretical: no stray tap happened in this run. Trigger to promote
  it: a run or a real game where a quarter is ended by mistake, or where undoing the end
  of a quarter proves hard.
- Suggested direction: owner's call. Either a confirmation, or make sure Undo plainly
  reverses an ended quarter.

### F4. Opponent is score-only; no sub prompt at foul-out

- Screen: live game.
- Events: 6, 9, 33.
- Expected (persona's wish, not required by the events): record the opponent's fouls (for
  our bonus), their timeouts, and a substitution prompt when #22 fouled out.
- Happened: none of these exist yet. No event's outcome was affected.
- Severity: polish. All three are already on the 1.0 checklist (opponent stats, active
  lineup with substitutions).

### F5. Opponent and "keep their score" are tucked in Game details; placeholder looks like a score

- Screen: New game.
- Event: 1.
- Expected: the opponent name and the keep-their-score option in plain view.
- Did: opened the collapsed "Game details" section to find them.
- Happened: found them, but the Opponent field's placeholder "11-16" (the date) looks like
  a score.
- Severity: polish.
- Suggested direction: a placeholder that reads as a team name, or none; consider showing
  the opponent and keep-their-score outside the collapsed section.
- Screenshot: v0.6.0/setup-game-details.png

### F6. Console error on load: favicon 404

- Screen: first load.
- Event: 1.
- Happened: `GET /favicon.ico` 404. The persona saw no effect.
- Severity: polish.
- Suggested direction: ship a favicon or point the page at an existing icon.

### F7. Book CSV doesn't record a foul-out

- Screen: Book CSV export.
- Event: 33, 44.
- Expected: #22 shown as out on 5 fouls (Q3), as the paper book would mark it.
- Happened: the row shows 5 fouls but no out marker or quarter.
- Severity: polish (missing field, not a wrong entry).
- Suggested direction: owner's call whether the Book CSV should carry it.

### F8. Timeout button "30" vs header "30s"

- Screen: Timeout choice and header.
- Event: 39.
- Happened: the choice reads "30", the header's count reads "30s". Clear enough to the
  persona.
- Severity: polish.
